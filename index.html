Metro UI Library

Componentes React/Next.js inspirados no Windows Phone

v1.0.0

📦 Instalação

npm install @andrevmoraes/metro-ui

Adicione no seu .npmrc: @andrevmoraes:registry=https://npm.pkg.github.com

🎨 Componentes Disponíveis

MetroButton
Botão estilo Metro com múltiplas variantes
  • variant: 'primary' | 'secondary' | 'ghost' | 'danger'
  • size: 'sm' | 'base' | 'lg'
  • accentColor: string
  • fullWidth: boolean
  • disabled: boolean
MetroTile
Tile quadrado/retangular no estilo Windows Phone
  • size: 'small' | 'medium' | 'wide' | 'large'
  • color: string
  • hoverable: boolean
  • onClick: () => void
MetroInput
Input de texto com design Metro
  • type: string
  • value: string
  • onChange: (value: string) => void
  • error: boolean
  • fullWidth: boolean
  • accentColor: string
MetroHeader
Cabeçalho de página estilo Metro
  • title: string
  • subtitle: string
  • onBack: () => void
  • action: ReactNode
  • accentColor: string
MetroLoading
Indicador de loading no estilo Windows
  • size: 'sm' | 'base' | 'lg'
  • color: string
  • text: string
  • fullScreen: boolean
MetroModal
Modal/Overlay para conteúdo
  • isOpen: boolean
  • onClose: () => void
  • maxWidth: 'sm' | 'md' | 'lg' | 'xl'
  • children: ReactNode
MetroStatsCard
Card para exibir estatísticas/métricas
  • value: string | number
  • label: string
  • color: string
  • icon: ReactNode

📐 Design System

ThemeColors
Paleta completa para temas claro e escuro
  • light.background, light.text, etc.
  • dark.background, dark.text, etc.
Typography
Sistema de tipografia Metro
  • fontFamily, fontSize, fontWeight
  • lineHeight, letterSpacing
Spacing
Escala de espaçamento consistente
  • 0, 1 (4px), 2 (8px), 3 (12px)...
  • Até 24 (96px)
Shadows & Transitions
Sombras sutis e transições suaves
  • Shadows: none, sm, base, md, lg, xl
  • Transitions: fast, base, slow

💻 Exemplo de Uso

import { MetroTile, MetroButton, MetroColors } from '@andrevmoraes/metro-ui';

export default function HomePage() {
  return (
    <div>
      <MetroTile 
        color={MetroColors.blue} 
        size="medium"
      >
        <h2>Meu Treino</h2>
      </MetroTile>
      
      <MetroButton variant="primary">
        Começar
      </MetroButton>
    </div>
  );
}
